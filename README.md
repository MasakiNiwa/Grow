# Grow

**人間改善プログラム** — 自分の傾向を知り、社会で生きていくための考え方を学び、練習して、ふりかえる。

🌐 **公開ページ**: https://masakiniwa.github.io/Grow/

## コンセプト

「知る → 学ぶ → 練習する → ふりかえる」の 4 つの柱を繰り返して、少しずつ成長していくためのアプリです。

| 柱            | 内容                                                                                                                                                                                                         |
| ------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 🧭 知る       | 性格（ビッグファイブ）・興味（RIASEC）・価値観の診断。Grow タイプ（16 タイプ）・興味のコード・大切にしたいことと、ドリルダウン。3 つのつながりを「総合プロフィール」で                                       |
| 📚 学ぶ       | 考え方カード（アサーション・傾聴・認知のゆがみ・リフレーミングなど）とクイズ。診断に合わせたおすすめと、FSRS による復習。外部の AI でカードを作って取り込める                                                |
| 🏋️ 練習       | 場面ロールプレイ（選択式／AI が相手役になって自由に）と、改善トレーニング（考え方の整理・3 つのよいこと・小さな習慣プラン）                                                                                  |
| 📈 ふりかえる | 日々のチェックインと分析ツール（週のレポート・総合プロフィール・推移・比較・ドリルダウン・コンディション・関係を探る（相関）・学びの記録・練習の記録）。キャラクターがまとめて分析し、CSV・JSON で書き出せる |

- 採点・タイプ分け・集計はプログラムが行い、AI はその上に乗る設計です（AI がなくても使えます）
- 🤖 **AI のキャラクター**: 相棒（ハル・ソラ先輩・ミナト・リコ・ねこ・カスタム）と、別の視点から一言添える 2 人目を選べます。診断の結果を構造化データで受け取り、ツールで記録を調べて、解説・相談・掘り下げをします
- ☁️ **クラウド AI**: Gemini・OpenAI・Claude・OpenRouter の API キーを 1 つの合言葉で暗号化して保存。場面ごとに使う AI を切り替えられます
- 💻 **端末内の AI**: LiteRT-LM で Gemma 4 などをブラウザ内で実行。モデルは同じ github.io のサイト（LLLM Study・Try Local など）と共有し、端末のファイルとしてバックアップもできます
- データはすべて端末のブラウザ内（IndexedDB）。バックアップの書き出し・復元ができます
- スマホ / PC 両対応（スマホは下部ナビ）、落ち着いたダークモード、PWA（オフライン起動）

> 診断は自己理解のための目安で、医学的・心理学的な診断ではありません。

## 開発

```bash
npm install
npm run dev        # 開発サーバー
npm run build      # 本番ビルド（dist/）
npm run lint       # ESLint
npm run typecheck  # TypeScript
npm test           # Vitest
npm run format     # Prettier
npm run licenses   # サードパーティのライセンス一覧（THIRD_PARTY_NOTICES.md）の生成
```

`main` ブランチへの push で GitHub Actions が GitHub Pages にデプロイします。
設計と拡張のしかたは [docs/SPEC.md](docs/SPEC.md) を参照してください。
