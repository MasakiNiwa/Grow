# Grow 仕様と設計

## 方針

- **判断はプログラム、AI は上乗せ**: 採点・タイプ分け・集計・分析はアルゴリズムで行う。AI はリアクション・解説・一緒に悩む・掘り下げを担当し、アプリの状態は構造化データ（JSON）で受け取る。AI がなくてもアプリとして使える
- **試行錯誤しても崩れない形**: 診断・分析ツール・（今後）教材やシナリオは「登録するだけで画面に出る」形にして、機能を足しても画面の構成を増やさない
- **ページは 4 つの柱に収める**: 知る・学ぶ・練習・ふりかえる。新しい機能はまずどの柱に入るかを考え、柱のページの中に置く
- **データは端末内**: IndexedDB（Dexie）。キー・DB 名には `grow` の接頭辞（同じ github.io のほかのサイトとぶつけない）

## 技術

| 用途         | 使うもの                                                                      |
| ------------ | ----------------------------------------------------------------------------- |
| 画面         | React 19 + TypeScript + Vite、Tailwind CSS v4、lucide-react、sonner           |
| ルーティング | wouter（ハッシュ。GitHub Pages 向け）                                         |
| 状態・データ | zustand（設定）、Dexie + dexie-react-hooks（記録）、zod（検証）               |
| グラフ       | Apache ECharts（必要な部品だけ読み込む）                                      |
| 並列処理     | Web Worker + Comlink（`src/lib/analysis`。Worker が使えなければその場で計算） |
| PWA          | vite-plugin-pwa（更新はユーザーが選ぶ）                                       |
| セキュリティ | 本番ビルドに CSP（`build/vite-plugin-csp.ts`。通信先を限定）                  |

## ディレクトリ

```
src/
  app/            レイアウト・ヘッダー・ナビ・テーマ
  components/     UI 部品（ui/）・グラフ（charts/）
  features/
    assess/       知る: 診断の型・採点・登録（registry.ts）・設問（instruments/）
    reflect/      ふりかえる: 分析ツールの登録（tools.ts）と各ツール
    settings/     設定（zustand + localStorage）
    help/         ヘルプの部品（ライセンス一覧・動作環境）
  lib/
    analysis/     分析の計算（純粋な関数）と Worker
    db/           IndexedDB とバックアップ
  pages/          ページ
```

## 拡張のしかた

- **診断を足す**: `features/assess/types.ts` の `Instrument` を作り、`registry.ts` の `INSTRUMENTS` に足す。回答・採点・保存・結果のドリルダウン・バックアップは共通で動く
- **分析ツールを足す**: コンポーネントを作り、`features/reflect/tools.ts` の `ANALYSIS_TOOLS` に 1 行足す。重い計算は `lib/analysis/analysis.ts` に関数を足すと Worker で動く
- **テーブルを足す**: `lib/db/db.ts` の version を上げて stores に追加し、`lib/db/backup.ts` の schema と書き出し・復元に足す

## UI のきまり

- ヘッダー右端は、どのページでも「ダークモードの切り替え」「ヘルプ」。ヘッダーに GitHub のアイコンは置かない。リリース履歴へのリンクはどこにも置かない
- 「クリア」はヘッダーの右側（ダークモードの左）。今の画面の入力・進行中の内容をリセットする（データ全体の削除は設定から）
- 設定・ヘルプは見出しごとに折りたたみ、既定はすべて閉じる。ヘルプのトップにバージョンなど
- スマホは下部ナビ、PC は左サイドバー
- ダークモードは彩度を抑えた配色（CSS 変数の差し替え。`src/index.css`）
